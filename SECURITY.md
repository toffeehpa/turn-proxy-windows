# Безопасность

## Сообщить об Уязвимости

Не открывайте публичный issue. Используйте **Security -> Report a vulnerability** в репозитории [toffeehpa/turn-proxy-windows](https://github.com/toffeehpa/turn-proxy-windows/security). Приложите версию FreeTurn, версию Windows и шаги воспроизведения; ключи и ссылки на звонки из логов уберите.

## Что Защищено

- **Секреты профиля**: ключ обфускации, Client ID и ссылки на звонки хранятся в `secure\<id>.bin` под DPAPI в контексте текущего пользователя. Расшифровать их может только этот пользователь на этом ПК
- **Логи**: секреты профиля заменяются на `***` и в строках ядра, и в командной строке запуска
- **Буфер обмена**: ссылка `freeturn://` при копировании помечается так, чтобы не попасть в журнал буфера (Win+V) и облачную синхронизацию
- **Named Pipe**: доступ только своему пользователю и SYSTEM, удалённые клиенты отклоняются, второй экземпляр проверяет SID сервера перед отправкой команды
- **Служба**: принимает от трея только профиль и проверяет его тем же `validate()`, что и GUI; командную строку ядра строит сама. Ядро запускает только из своей папки в Program Files, куда без прав администратора не записать
- **Пайп службы**: интерактивные пользователи могут только обмениваться сообщениями, удалённые клиенты отклоняются; трей отдаёт профиль, только если пайпом владеет LocalSystem
- **Процесс ядра**: в Job Object службы, наследует только свои хэндлы, при падении службы завершается; трей закрылся - ядро остановлено
- **Ядро в сборке**: версия закреплена в `core.version`, CI берёт файл только из релиза ядра на github.com и сверяет SHA-256 с `checksums.txt`
- **Права**: трей - `asInvoker`, без повышения прав; администратор нужен только установщику. DLL загружаются только из System32

## Ограничения

> [!WARNING]
> **Параметры ядру передаются командной строкой**, включая `-obf-key`, `-client-id` и `-links`: у CLI ядра нет другого входа. Ядро работает от SYSTEM, поэтому его командную строку видят только администраторы машины.

- **Служба общая для машины**: подключение может запустить любой интерактивный пользователь этого ПК, а маршруты ядра действуют для всей системы
- **DPAPI** защищает от чтения файлов другим пользователем или на другом ПК, но не от программ, запущенных под вашей учётной записью
- **Ручная капча**: ядро открывает браузер само, FreeTurn в этом не участвует
- **Подпись**: сборки пока не подписаны - [CODE_SIGNING.md](CODE_SIGNING.md)
