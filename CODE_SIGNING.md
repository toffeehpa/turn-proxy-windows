# Подпись Кода

> [!WARNING]
> **Сборки FreeTurn сейчас не подписаны.** Windows SmartScreen может предупредить при первом запуске.

## Что Подготовлено

- **VERSIONINFO** в `FreeTurn.exe` и `freeturn-service.exe`: имя продукта, версия, оригинальное имя файла
- **Манифест**: `asInvoker`, без запроса прав администратора
- **Без упаковщиков**: никаких UPX и обфускации - бинарник должен проверяться как есть

## План

- **SignPath Foundation**: бесплатная подпись для открытых проектов. Нужны заявка, публичный репозиторий и сборка в GitHub Actions - подписываться будут артефакты CI (exe и MSI), а не локальная сборка
- **Ядро**: `freeturn-core.exe` - бинарник из релизов free-turn-proxy, его подпись - дело ядра. CI сверяет его SHA-256 с `checksums.txt` релиза ядра перед упаковкой - [BUILDING.md](BUILDING.md)

Пока подписи нет, проверяйте SHA-256 файлов по странице релиза.
